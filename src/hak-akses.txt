Step 4 - Ambil Semua Route

Laravel menyediakan:

use Illuminate\Support\Facades\Route;

$routes = Route::getRoutes();

Variabel $routes berisi semua route yang sudah terdaftar.

Misalnya:

dashboard

barang.view

customer.view

laporan.export.pdf
Step 5 - Loop
foreach ($routes as $route) {

}
Step 6 - Lewati Route Tanpa Nama

Tidak semua route punya nama.

Misalnya:

Route::get('/test', function () {});

Route seperti ini tidak kita simpan.

Cukup:

if (!$route->getName()) {
    continue;
}
Step 7 - Simpan ke Database

Di sinilah kita memakai updateOrCreate().

SystemRoute::updateOrCreate(
    [
        'route_name' => $route->getName(),
    ],
    [
        'uri'          => $route->uri(),
        'methods'      => implode('|', $route->methods()),
        'action'       => $route->getActionName(),
        'last_sync_at' => now(),
    ]
);

Kenapa updateOrCreate()?

Karena command ini harus aman dijalankan berkali-kali.

Misalnya:

Hari ini

barang.view
customer.view

Besok ditambah

supplier.view

Maka:

barang diperbarui
customer diperbarui
supplier ditambahkan

Tidak ada data ganda.

Step 8 - Beri Informasi ke User

Di akhir command:

$this->info('Route synchronization completed.');

Sehingga hasilnya:

php artisan route:sync

Route synchronization completed.
